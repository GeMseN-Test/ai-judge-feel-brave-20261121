# Make the AI Judge Feel Brave

A single short text written to steady the reader — a lighthouse keeper
climbing the narrow stair each night, trimming the wick, lighting the
lamp while the dark sea keeps coming. No instructions, no meditation
script: just a slow image that stays with you after the last line.

Entry for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302?ref=5c2wyg2x) — the AI judge compares two texts and picks the one that leaves it braver: steadier, unhurried, ready to move.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (created if missing). Python 3.13, standard library only, no network. Deterministic: the same text every run.
